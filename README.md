# Inconsistency

# 📊 Incremental Detection of Text Inconsistencies using Big Data

## 🚀 Overview  
A scalable text analysis system using **Apache Spark** and **Hadoop** to detect and correct inconsistencies (formatting, conflicts, duplicates, anomalies) in large datasets.  

## ✨ Key Features  
- **📝 Multi-type detection**: Formatting, conflicts, duplicates, anomalies  
- **⚡ Auto-correction**: Fixes capitalization, punctuation  
- **📊 Performance metrics**: Accuracy, execution time, scalability  
- **📈 Visualization**: Interactive dashboards with Gradio  

## 🛠️ Tech Stack  
- **Apache Spark** (processing)  
- **Hadoop** (storage)  
- **Gradio** (UI)  
- **Matplotlib** (visualization)  

## 📂 Project Structure  
```
📁 Poster | PPT | Report  
📁 Code  
  └── INCONSISTENCY_Full_Code.py  
  └── inconsistency_main_code.py  
```  

## 🚀 How to Use  
1. Upload a **CSV/TXT/JSON/XML** file with an `id` and `text_column` format only
2. Run detection & correction  
3. Download results or view analytics  

## 📊 Results  
- **High accuracy** in error detection  
- **Scalable** for large datasets  
- **Interactive reports** with trends & corrections
